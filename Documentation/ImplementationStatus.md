# AlgomateColony 実装状況

## 判定方法

- **実装済み**：対象となる処理経路がコードとデータで確認できる。Unity上の通し動作保証とは区別する。
- **部分実装**：一部の機能があるが、入出力から成功結果までの完結性・エラー処理・UI連携などが不足または未検証。
- **未実装**：既存資料で予定・要求として記されているが、該当する実行処理を確認できない。
- **構想段階**：開発者メモやストーリー案にある将来アイデア。実装済みの仕様ではない。
- **要確認**：アセット参照、Unity実行時挙動、意図、提供範囲をリポジトリだけでは決定できない。

実査範囲は `Assets/Scripts`、主要なResources JSON、関連ScriptableObject・Prefab、既存README・企画資料です。Unity Editorでのプレイテストは未実施です。各フローの詳細は [LogicFlows.md](./LogicFlows.md)、現行ルールの整理は [GameSpecification.md](./GameSpecification.md) を参照してください。

|---|---|---|---|
| ロボットPrefab生成 | 実装済み | `GameManager.Start()` → `RobotFactory.CreateRobot()` → `RobotController.SpawnInit()`。起動時に1回生成。 | Prefab・SpawnPoint参照が現在のSceneで有効か、Editor実行は未確認。 |
| ロボット選択・状態表示 | 部分実装 | `RobotStatusPanelManager.SetRobotStatus()` が対象ロボットのデータ・所持Slot・コマンドUIを設定。 | 複数体を通常運用した場合の選択・切替・同時実行を確認していない。 |
