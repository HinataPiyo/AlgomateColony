# 🤖 アルゴリズム・コロニー - ゲーム説明書

## 📖 ゲームの概要

「アルゴリズム・コロニー」は、プレイヤーが神の視点からロボットたちに命令（プログラミング）を与え、自動化されたコロニーを運営・発展させていくシミュレーションゲームです。

ロボットに資源の収集、運搬、加工などを指示し、あなたの手でコロニーを豊かにしていきましょう。
ゲームを進めることで、より複雑で高度な命令をプログラムできるようになり、ロボットたちの作業効率を最適化していく楽しみが味わえます。

---

## 🎮 操作方法

このゲームでは、プレイヤーがキャラクターを直接操作することはありません。主な操作は以下の通りです。

1.  **🤖 ロボットの選択:**
    *   マップ上のロボットを選択します。
2.  **⌨️ コマンドの入力:**
    *   選択したロボットに対して、画面に表示されるコマンドリストから命令を与えます。
    *   最初は「移動（Move）」や「収集（Gather）」,「格納（Deposit）」といった基本的なコマンドから始まります。
    *   **💡ヒント:** コマンドの概要は右上の設定ボタンから確認できます。
3.  **🏭 施設の利用:**
    *   拠点をクリックすることで、施設のアップグレードや新しいコマンドの研究が可能です。

ゲームの目的は、これらのコマンドを組み合わせてロボットの行動を自動化し、効率的な生産ラインを構築することです。

## ⚙️ 現在のバージョンでプレイ可能な範囲

このバージョンは開発中のプロトタイプです。以下の内容を体験いただけます。

### ✅ プレイ可能なこと

*   ロボットへの基本的な命令（指定位置への移動、資源の収集、資源の格納）。
*   収集した資源を拠点へ運搬すること。
*   基本的なUIによる資源量や拠点レベルの確認、レベルアップ。

## 左下のコマンド入力するところについて

主にユーザーの助けになればと思い作っているものになります。
例えば「cmd:setting」と打てば設定画面が開きます。
現在実装しているのは、

*   cmd:setting
*   cmd:location

のみとなります。  
ちなみに、「c」を入力し、Tabキーを押すと「cmd:」が入力されます。

### 🚧 今後実装予定の要素（現在はプレイできません）

*   `if`文や`for`ループなどを用いた高度なプログラミング機能。
*   資源を加工する「加工工場」やアイテムを保管する「倉庫」などの多様な施設。
*   ロボットのエネルギー管理や修理。
*   クエストや他のコロニーとの交易。
*   新しいコマンドのアンロックや研究。

## ✨ はじめに

最初はチュートリアルに沿って進めていただければ問題ありません。
現在はゲームのコアとなる「ロボットへの命令と資源収集」の部分を体験できる状態です。ぜひ、ロボットたちがあなたの命令通りに働く様子をお楽しみください。

### 💡 こんな書き方もできます

> 鉄鉱石と木材を集めて倉庫に格納する例
```csharp
Move(ironOre);
Gather(ironOre);
Move(tree);
Gather(tree);
Move(warehouse);
Deposit(ironOre, 30);
Deposit(tree, 30);
```

### ⚠️ 注意事項

もし、ロボットがオブジェクトに引っかかることがあれば、再度実行するか、一度別のオブジェクトに移動してみて下さい。
