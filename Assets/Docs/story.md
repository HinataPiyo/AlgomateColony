# Story and Vision / ストーリーと企画背景

このページは世界観とデザイン意図をまとめた資料です。  
This page explains world context and design intent.

- プレイヤー向けマニュアル: [README.md](./README.md)
- 開発者向け技術資料: [documentation.md](./documentation.md)

## 1. Premise / 前提

You are not a single character on the field. You are the colony strategist issuing instructions to robots from a higher perspective.  
プレイヤーは現場の1キャラクターではなく、上位視点からロボットに命令を与えるコロニー運営者です。

## 2. Fantasy and Emotion / 体験の核

- Planning over direct action
- Satisfaction from automation
- Optimization through repeated command tuning

- 直接操作より計画
- 自動化が回る快感
- 命令最適化による達成感

## 3. Current Play Experience / 現在の体験設計

The current prototype focuses on a simple but readable automation loop:

1. Choose a robot
2. Issue Move/Gather/Deposit commands
3. Observe execution and logistics
4. Feed collected materials into colony progression

現行プロトタイプは、次のシンプルな自動化ループを重視しています。

1. ロボットを選ぶ
2. Move/Gather/Deposit を入力する
3. 実行と運搬結果を観察する
4. 集めた資源を進行へ回す

## 4. World Tone / 世界観トーン

- Robotics and resource logistics
- Colony growth through systems, not combat-first gameplay
- Practical interface with command literacy as progression flavor

- ロボティクスと資源物流
- 戦闘中心ではなくシステム運営で発展するコロニー
- コマンド理解そのものが成長実感になる設計

## 5. Planned Narrative/Design Expansion / 今後の拡張方針

Planned ideas include:

- Expanded command language (conditional/loop constructs)
- More facility roles (processing, research, additional automation)
- Broader colony relationships and long-term objectives

今後の方向性として、次を想定しています。

- 条件分岐やループなど命令言語の拡張
- 加工・研究・自動化施設の役割拡張
- 他コロニーとの関係性や長期目標の拡張

本資料は実装済み範囲と将来構想を分離しています。プレイ可能範囲は README、技術詳細は documentation を参照してください。
