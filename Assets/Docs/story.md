# 世界観・企画背景（統合先）

このページに記載していた企画情報を、作品紹介と将来構想へ統合しました。

- 世界観、プレイヤーの役割、体験の軸、現在のゲームループ：[GameOverview.md](../../Documentation/GameOverview.md)
- 実装済み範囲と企画上の構想の区分：[ImplementationStatus.md](../../Documentation/ImplementationStatus.md)
- 研究・施設・他コロニー・長期目標等の拡張案：[FutureRoadmap.md](../../Documentation/FutureRoadmap.md)

荒廃した惑星、稼働限界に近いロボットの再起動、失われた文明の技術という記述は、既存企画資料に書かれた世界観です。対応する探索・研究システムが現行コードで実装されているという意味ではありません。

既存資料が明示する体験の軸は「直接操作より計画」「自動化が回る快感」「命令最適化による達成感」です。これらは企画意図として記載し、プレイヤーへの効果が検証済みであるとは表現しません。
