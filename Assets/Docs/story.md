# ストーリーと企画背景

このページは世界観とデザイン意図をまとめた資料です。  

- プレイヤー向けマニュアル: [README.md](./README.md)
- 開発者向け技術資料: [documentation.md](./documentation.md)

## 1. 前提

プレイヤーは現場の1キャラクターではなく、上位視点からロボットに命令を与えるコロニー運営者です。
  荒廃した惑星に降り立ったあなたは、稼働限界が近いロボットたちを再起動し、失われた文明の技術を集めながら新たな拠点を築きます。
  しかし、惑星の環境は過酷で、資源もエネルギーも不足気味です。限られた命令をどう組み合わせるかで、コロニーの未来は大きく変わります。
  研究を進めるごとにロボットは賢くなり、単純作業だった運営はやがて巨大な自動化システムへと進化していきます。

## 2. 体験の核

- 直接操作より計画
- 自動化が回る快感
- 命令最適化による達成感

## 3. 現在の体験設計

現行プロトタイプは、シンプルで分かりやすい自動化ループを重視しています。

1. ロボットを選ぶ
2. Move/Gather/Deposit を入力する
3. 実行と運搬結果を観察する
4. 集めた資源を進行へ回す

## 4. 世界観トーン

- ロボティクスと資源物流
- 戦闘中心ではなくシステム運営で発展するコロニー
- コマンド理解そのものが成長実感になる設計

## 5. 今後の拡張方針

今後の方向性として、次を想定しています。

- 条件分岐やループなど命令言語の拡張
- 加工・研究・自動化施設の役割拡張
- 他コロニーとの関係性や長期目標の拡張
